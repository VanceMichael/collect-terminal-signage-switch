# 资料提供方的格式

`/events.json` 由节目组发布，parts 各行依次为独立场次、厅、起止分钟、稿版与模板。r2 只替换部分场次。`/concourse.json` 由运控发布，有向通道附开放区间和步行分钟数，适用区间左闭右开。`/players.csv` 给屏所在区域、订阅区域和频道。`/distribution.json` 是后台接受记录，说明由哪个发布者向哪些频道提交内容及生效期，不代表实际播出。
播放器查看从 `/player` 网页选择屏号和巡检轮次。现场回读同时显示活动稿版本、模板版、缓存生成分钟和实际显示期，1 表示现场旧轮，2 表示改场后轮。屏的发布范围由运控配置的区域与订阅共同限制，不由节目名称决定。
`/playout` 是发布人员的分区投递页，按区域、频道、稿版和模板递交。收到 PUB 系列回执后仍须查播放器。P2-待定 是节目组不含路线的待定稿，使用通用模板 T0。
